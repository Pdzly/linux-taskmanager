# Support TaskMonitor

TaskMonitor is free and open source (MIT). If it saves you time or you simply like it, you can support its development.

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/V8G5225SN8)

## Donate

**[ko-fi.com/anujdhakal](https://ko-fi.com/anujdhakal)**: one-off or monthly, any amount.

Donations go towards:

- time to fix bugs and build the features people ask for
- testing on more distros and hardware (AMD GPUs, ARM, other desktops)
- getting TaskMonitor into more app stores (Flathub, Snap Store)

## Other ways to help

Money isn't the only way to support the project, and these help just as much:

- **Star the repository** on [GitHub](https://github.com/anuzdhk/linux-taskmanager). It helps others find it.
- **Report bugs and ideas** in [Issues](https://github.com/anuzdhk/linux-taskmanager/issues). Include your distro, desktop and what you expected.
- **Share it** with friends, on Reddit or wherever Linux users hang out.
- **Contribute code**: pull requests are welcome; see the [README](README.md#build-from-source) to build it.
- **Join the community** on [Discord](https://discord.gg/NpS9WmSW23).

Thank you! ❤️
